# REFLEX OPS

REFLEX OPS is the terminal workspace for Paragon Reflex: your own AI agent, working on your own machine, with your
work kept private by default.

## Install

```sh
curl -fsSL https://reflex.riif.com/install | bash
```

Then sign in:

```sh
reflex login
```

Builds for macOS, Linux and Windows are under [Releases](../../releases). Installed copies update themselves.
